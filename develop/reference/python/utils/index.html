    frappe.utils¶

    frappe.utils holds helpers for type conversion, dates, numbers, strings, URLs, HTML, paths and files. Use this page to look up the exact signature, default, return value and side effect of a helper. Most helpers live in frappe/utils/data.py. frappe/utils/__init__.py imports all of frappe.utils.data with from frappe.utils.data import *, so import them from frappe.utils:

    from frappe.utils import add_days, cint, flt, getdate, nowdate

    Helpers in submodules (frappe.utils.file_manager, frappe.utils.password and others) are not re-exported. Import them from the submodule.

    Signatures come from the code. DateTimeLikeObject means str | datetime.date | datetime.datetime. NumericType means int | float. A function marked "Whitelisted" can be called over HTTP at /api/method/<dotted.path>. "All methods" means GET, POST, PUT, DELETE and QUERY.

    Note

    The star import also re-exports names that frappe/utils/data.py imports, such as relativedelta, parser, slug, get_date_format and NumberFormat. Import those from their own modules. This page does not list them, except NumberFormat.

    Example output¶

    These results come from the develop site. The site has date format dd-mm-yyyy, number format #,##,###.##, time zone Asia/Kolkata and no currency precision.

    from frappe.utils import (
    add_days, add_to_date, cint, comma_and, date_diff, flt, fmt_money, format_duration,
    get_last_day, getdate, rounded,
)

cint("12.7")                            # 12
cint("1,234")                           # 0
cint(None, 5)                           # 5
flt("1,234.567", 2)                     # 1234.57
flt(1.005, 2)                           # 1.0  (banker's rounding, legacy)
rounded(2.5)                            # 2.0
getdate("2026-01-15")                   # datetime.date(2026, 1, 15)
getdate("")                             # today, as datetime.date
add_days("2026-01-31", 1)               # '2026-02-01'  (string in, string out)
add_days(getdate("2026-01-31"), 1)      # datetime.date(2026, 2, 1)
add_to_date("2026-01-31", months=1)     # '2026-02-28'
date_diff("2026-03-01", "2026-02-01")   # 28
get_last_day("2024-02-03")              # datetime.date(2024, 2, 29)
fmt_money(1234567.891)                  # '12,34,567.89'
format_duration(93784)                  # '1d 2h 3m 4s'
comma_and(["a", "b", "c"])              # "'a', 'b', and 'c'"

    Type conversion and JSON¶

    Function Description
    cint(s: NumericType \| str \| None, default: int = 0) -> int Convert to int. A float string is truncated ("12.7" gives 12). A string with commas gives default. Returns default when conversion fails.
    flt(s: NumericType \| str \| None, precision: int \| None = None, rounding_method: str \| None = None) -> float Convert to float. Removes commas from strings. Returns 0.0 when conversion fails. Rounds with rounded() when precision is set.
    cstr(s, encoding="utf-8") -> str Convert to str. None gives "". Decodes bytes with encoding.
    sbool(x: str \| Any) -> bool \| str \| Any "true" and "1" give True. "false" and "0" give False. Case does not matter. Other values come back unchanged.
    cast(fieldtype, value=None) Cast to the Python type of a Frappe fieldtype. Float, Currency, Percent use flt. Int, Check use cint(sbool(value)). Text and link types use cstr. An empty Date gives date(1, 1, 1). An empty Datetime gives datetime(1, 1, 1). Time gives a timedelta. Other fieldtypes return value.
    parse_json(val: Any) Parse a JSON string with orjson. A dict result becomes frappe._dict. Other values come back unchanged.
    parse_val(v) Convert SQL result values to simple types. date and datetime become str. timedelta becomes "h:mm".
    orjson_dumps(obj, default=None, option=None, decode=True) orjson.dumps with OPT_PASSTHROUGH_DATETIME and OPT_NON_STR_KEYS. Returns str if decode is true, else bytes. Dates need a default such as frappe.utils.response.json_handler.
    safe_json_loads(*args) Parse each argument as JSON. Keep an argument as it is if it does not parse. One argument gives one value, more give a list.
    dictify(arg) Convert dicts, also dicts inside lists, to frappe._dict. Changes lists in place.
    encode(obj, encoding="utf-8") Encode a str to bytes. Other values come back unchanged.
    safe_encode(param, encoding="utf-8") Encode a str to bytes. Ignores errors.
    safe_decode(param, encoding="utf-8", fallback_map: dict \| None = None) Decode bytes to str. Returns param unchanged on failure. fallback_map maps an unknown encoding to a known one.
    as_unicode(text, encoding: str = "utf-8") -> str bytes are decoded, None gives "", other values go through str().
    encode_dict(d, encoding="utf-8") Encode every str value of d to bytes. Changes d in place.
    decode_dict(d, encoding="utf-8") Does nothing. Its condition is always false. Returns d.

    Current date and time¶

    All values use the system time zone from System Settings.

    Function Description
    now() -> str Current datetime, for example "2026-11-22 17:16:59.229329" (with microseconds).
    now_datetime() -> datetime.datetime Current datetime as a naive datetime.
    nowdate() -> str Current date as yyyy-mm-dd.
    today() -> str Same as nowdate().
    nowtime() -> str Current time, for example "17:16:59.229439" (with microseconds).
    get_timestamp(date: DateTimeLikeObject \| None = None) -> float Unix timestamp of the start of the date in the server local time. None gives today.
    get_eta(from_time: DateTimeLikeObject, percent_complete) -> str Estimated time left as a timedelta string, from the start time and the percent done.

    Parse and convert dates¶

    Function Description
    getdate(string_date: DateTimeLikeObject \| None = None, parse_day_first: bool = False) -> datetime.date \| None Convert to date. None or "" gives today. "0000-00-00" and "0001-01-01" give None. A string that does not parse raises frappe.ValidationError.
    get_datetime(datetime_str: DateTimeLikeObject \| None \| tuple \| list = None) -> datetime.datetime \| None Convert to datetime. None gives now. A date gives midnight. "" gives None. A timedelta comes back unchanged. A tuple or list raises TypeError.
    get_time(time_str: str \| datetime.datetime \| datetime.time \| datetime.timedelta) -> datetime.time Convert to time.
    get_timedelta(time: str \| datetime.timedelta \| None = None) -> datetime.timedelta \| None Convert a time string such as "10:20:30" to timedelta.
    to_timedelta(time_str: str \| datetime.time) -> datetime.timedelta Convert a string or time to timedelta.
    get_date_str(date_obj: DateTimeLikeObject) -> str Date as yyyy-mm-dd.
    get_datetime_str(datetime_obj: DateTimeLikeObject) -> str Datetime as yyyy-mm-dd hh:mm:ss.ffffff. "2026-01-15" gives "2026-01-15 00:00:00.000000".
    get_time_str(timedelta_obj: datetime.timedelta \| str) -> str Time as h:m:s with no zero padding. 1:02:03 gives "1:2:3". Drops days.
    guess_date_format(date_string: str) -> str strftime format of a date string, for example "%d-%m-%Y".
    is_invalid_date_string(date_string: str) -> bool True if the value is not a string, is empty, or starts with 0001-01-01 or 0000-00-00. It does not check the format.

    Date arithmetic¶

    A string input gives a string output. A date or datetime input gives the same type.

    Function Description
    add_to_date(date: DateTimeLikeObject \| None = None, years=0, months=0, weeks=0, days=0, hours=0, minutes=0, seconds=0, as_string=False, as_datetime=False) -> DateTimeLikeObject Add any mix of units with relativedelta. None uses now. Month ends clamp: 2026-01-31 plus one month is 2026-02-28. See the pitfalls for strings.
    add_days(date: DateTimeLikeObject, days: NumericType) -> DateTimeLikeObject Add days.
    add_months(date: DateTimeLikeObject, months: NumericType) -> DateTimeLikeObject Add months.
    add_years(date: DateTimeLikeObject, years: NumericType) -> DateTimeLikeObject Add years. 2024-02-29 plus one year is 2025-02-28.
    date_diff(string_ed_date: DateTimeLikeObject, string_st_date: DateTimeLikeObject) -> int Days from start to end. Negative if end is before start.
    days_diff(string_ed_date: DateTimeLikeObject, string_st_date: DateTimeLikeObject) -> int Same as date_diff.
    month_diff(string_ed_date: DateTimeLikeObject, string_st_date: DateTimeLikeObject) -> int Months between two dates, counting both partial months. month_diff("2026-03-01", "2026-01-15") is 3.
    time_diff(string_ed_date: DateTimeLikeObject, string_st_date: DateTimeLikeObject) -> datetime.timedelta Difference as timedelta.
    time_diff_in_seconds(string_ed_date: DateTimeLikeObject, string_st_date: DateTimeLikeObject) -> float Difference in seconds.
    time_diff_in_hours(string_ed_date: DateTimeLikeObject, string_st_date: DateTimeLikeObject) -> float Difference in hours.

    Week, month, quarter and year¶

    Functions with as_str return a yyyy-mm-dd string when as_str=True, else a date. The first day of the week comes from System Settings (first_day_of_the_week), Sunday by default.

    Function Description
    get_first_day(dt, d_years: int = 0, d_months: int = 0, as_str: bool = False) -> str \| datetime.date First day of the month of dt, after moving d_years and d_months.
    get_last_day(dt) Last day of the month as date.
    is_last_day_of_the_month(dt) True if dt is the last day of its month.
    get_first_day_of_week(dt: DateTimeLikeObject, as_str=False) -> datetime.date \| str First day of the week of dt.
    get_last_day_of_week(dt: DateTimeLikeObject, as_str=False) -> datetime.date \| str Last day of the week of dt.
    get_quarter_start(dt: DateTimeLikeObject \| None = None, as_str: bool = False) -> str \| datetime.date First day of the quarter. None uses today.
    get_quarter_ending(date: DateTimeLikeObject \| None = None, as_str=False) -> str \| datetime.date Last day of the quarter.
    get_year_start(dt: DateTimeLikeObject, as_str=False) -> str \| datetime.date 1 January of the year.
    get_year_ending(date: DateTimeLikeObject \| None = None, as_str=False) -> datetime.date \| str 31 December of the year.
    get_timespan_date_range(timespan: TimespanOptions) -> tuple[datetime.date, datetime.date] \| None (start, end) for a timespan filter value: "last week", "last month", "last quarter", "last 6 months", "last year", "yesterday", "today", "tomorrow", "this week", "this month", "this quarter", "this year", "next 7 days", "next 14 days", "next 30 days", "next week", "next month", "next quarter", "next 6 months", "next year".
    get_weekday(datetime: DateTimeLikeObject \| None = None) -> str English weekday name, for example "Sunday". None uses now.
    get_weekdays() -> list[str] Weekday names from "Monday" to "Sunday".
    get_month(datetime: DateTimeLikeObject \| None = None) -> str English month name, for example "January".
    get_start_of_week_index() -> int Index of the first day of the week, 0 for Sunday.
    get_normalized_weekday_index(dt: datetime.date \| datetime.datetime) -> int Weekday index with Sunday as 0.
    get_week_start_offset_days(dt: datetime.date \| datetime.datetime) -> int Days from the first day of the week to dt.
    Weekday Enum from Sunday = 0 to Saturday = 6.

    Time zones¶

    Function Description
    get_system_timezone() -> str System time zone name from System Settings, for example "Asia/Kolkata".
    get_timezone_utc_offset(timezone: str) -> str Current UTC offset as ±HH:MM, for example "+05:30".
    get_datetime_in_timezone(time_zone: str) -> datetime.datetime Current datetime in a time zone. The result is aware.
    convert_utc_to_timezone(utc_timestamp: datetime.datetime, time_zone: str) -> datetime.datetime Convert a UTC datetime to an aware datetime in time_zone.
    convert_utc_to_system_timezone(utc_timestamp: datetime.datetime) -> datetime.datetime Convert a UTC datetime to an aware datetime in the system time zone.
    validate_time_zone(time_zone: str) -> None Raise frappe.ValidationError if the name is not in zoneinfo.available_timezones().

    Format for display¶

    These use the format of the current user and System Settings. To format a value by fieldtype, use frappe.format_value.

    Function Description
    format_date(string_date=None, format_string: str \| None = None, parse_day_first: bool = False) -> str Format a date with Babel in the user date format. format_string uses Babel patterns, for example "dd MMM yyyy". None gives "".
    formatdate Alias of format_date.
    format_time(time_string=None, format_string: str \| None = None) -> str Format a time in the user time format.
    format_datetime(datetime_string: DateTimeLikeObject, format_string: str \| None = None) -> str Format a datetime in the user date and time format. No time zone conversion.
    global_date_format(date: DateTimeLikeObject, format="long") -> str Localized date in the current language. "long" gives "January 15, 2026", "short" gives "1/15/26".
    pretty_date(iso_datetime: datetime.datetime \| str, mini=False) -> str Relative time, for example "2 hours ago". mini=True gives "2h".
    get_user_date_format() -> str Date format of the current user, for example "dd-mm-yyyy". Cached in frappe.local for the request.
    get_user_format Alias of get_user_date_format.
    get_user_time_format() -> str Time format of the current user, for example "HH:mm:ss". Cached in frappe.local.

    Durations and timedelta¶

    Function Description
    format_duration(seconds: float \| int, hide_days: bool = False) -> str 93784 gives "1d 2h 3m 4s". hide_days=True gives "26h 3m 4s".
    duration_to_seconds(duration: str) -> int "1d 2h 3m 4s" gives 93784.
    validate_duration_format(duration: str) -> None Raise frappe.ValidationError if the string is not in the d h m s format.
    format_timedelta(o: datetime.timedelta \| str) -> str Format as h:mm:ss. Hours can be more than 23 ("25:01:02"). Used for Time values in JSON.
    parse_timedelta(s: str) -> datetime.timedelta Parse str(timedelta) output such as "1 day, 2:03:04".

    Numbers and money¶

    Rounding uses the rounding_method from System Settings. The default is "Banker's Rounding (legacy)". The other values are "Banker's Rounding" and "Commercial Rounding". Another value raises frappe.InvalidRoundingMethod.

    Function Description
    rounded(num, precision=0, rounding_method=None) Round with the given or system rounding method. rounded(2.5) is 2.0, rounded(3.5) is 4.0.
    ceil(s: NumericType \| str) -> int Round up.
    floor(s: NumericType \| str) -> int Round down.
    safe_div(numerator: NumericType, denominator: NumericType, precision: int = 2) -> float Divide and round. A 0 denominator gives 0.0.
    remainder(numerator: NumericType, denominator: NumericType, precision: int = 2) -> NumericType Remainder of the division, rounded.
    get_currency_precision() -> int \| None currency_precision from System Settings, or None if not set.
    round_based_on_smallest_currency_fraction(value, currency, precision=2) Round to the smallest_currency_fraction_value of the Currency.
    fmt_money(amount: str \| float \| int \| None, precision: int \| None = None, currency: str \| None = None, format: str \| None = None) -> str Format with the number format of the user or format. Adds the currency symbol when currency is set. None or an invalid string gives "0.00".
    money_in_words(number: str \| float \| int, main_currency: str \| None = None, fraction_currency: str \| None = None) Amount in words, for example "USD One Thousand, Two Hundred And Fifty and Fifty Cent only.". The default currency is the currency default, else INR. A negative or invalid number gives "".
    in_words(integer: int, in_million=True) -> str Integer in words. in_million=False uses lakh and crore.
    NumberFormat(precision: int, decimal_separator: str, thousands_separator: str, string: str) Parsed number format. Make one with NumberFormat.from_string("#,###.##"). Defined in frappe.utils.number_format.

    Strings¶

    Function Description
    scrub(txt: str) -> str Lowercase and replace spaces and hyphens with _. "Sales-Order 2" gives "sales_order_2".
    unscrub(txt: str) -> str Replace _ and - with spaces and title-case. "sales_order" gives "Sales Order".
    strip(val: str, chars: str \| None = None) -> str Remove all \ufeff and \u200b characters, then strip whitespace or chars from both ends. None gives "".
    get_abbr(string: str, max_len: int = 2) -> str First letters of up to max_len words. Keeps the case. "Example Corp" gives "EC".
    random_string(length: int) -> str Random letters and digits from secrets.
    generate_hash(*args, **kwargs) -> str Same as frappe.generate_hash. Hex string of 56 characters by default. Pass length.
    sha256_hash(input: str \| bytes) -> str SHA-256 hex digest.
    is_sha256_hash(value: str) -> bool True if the value has 64 hex characters.
    comma_and(some_list: list \| tuple, add_quotes=True) -> str "'a', 'b', and 'c'". Translates each item except the last.
    comma_or(some_list: list \| tuple, add_quotes=True) -> str "'a', 'b', or 'c'".
    comma_sep(some_list: list \| tuple, pattern: str, add_quotes=True) -> str Join all items but the last with commas, then join with the last using pattern, for example "{0} or {1}".
    new_line_sep(some_list: list \| tuple) -> str Join with "\n " (new line and a space).
    filter_strip_join(some_list: list[str], sep: str) -> str Drop empty items, strip each, then join with sep.
    list_to_str(seq, sep=", ") Convert each item to str, strip it, then join with sep.
    get_string_between(start: str, string: str, end: str) -> str Text between start and end. These are regex patterns. Returns string if there is no match.
    esc(s, esc_chars) Put a backslash before each of esc_chars in s.
    unesc(s, esc_chars) Remove the backslash before each of esc_chars.
    bold(text: str \| int \| float) -> str Wrap in <strong>. Same as frappe.bold.
    sanitize_column(column_name: str) -> str Raise frappe.ValidationError if a column name or expression has unsafe SQL. Returns the name.
    get_table_name(table_name: str, wrap_in_backticks: bool = False) -> str "ToDo" gives "tabToDo". Names that start with __ stay the same.

    Lists and dicts¶

    Function Description
    unique(seq: Sequence[T]) -> list[T] Remove duplicates and keep the order.
    has_common(l1: Hashable, l2: Hashable) -> bool Common items as a set. The set is truthy when there is a match.
    is_subset(list_a: list, list_b: list) -> bool True if every item of list_a is in list_b.
    create_batch(iterable: Iterable, size: int) -> Generator[Iterable] Yield slices of at most size items. The input must support len() and slicing.
    dict_with_keys(dict, keys) New dict with only keys.
    remove_blanks(d: dict) -> dict Remove all falsy values, also 0. Changes d in place.
    dict_to_str(args: dict[str, Any], sep: str = "&") -> str URL query string. None values become empty.
    groupby_metric(iterable: dict[str, list], key: str) Regroup {category: [records]} as {record[key]: {category: [records]}}.
    squashify(what) Return the only item of a one-item sequence. Other values come back unchanged.
    recursive_defaultdict() defaultdict that makes nested defaultdicts on access.

    Filters and comparison¶

    These evaluate Frappe filters in Python, without a database query.

    Function Description
    evaluate_filters(doc: Mapping, filters: FilterSignature) True if doc matches all filters. doc must have a doctype key, else Filters raises ValueError. Supports descendants of and the other tree operators.
    compare(val1: Any, condition: str, val2: Any, fieldtype: str \| None = None) -> bool Compare with a filter operator. Casts with cast() when fieldtype is set. An unknown operator returns False.
    get_filter(doctype: str, filters: FilterSignature, filters_config=None) -> frappe._dict Normalize the first filter to {doctype, fieldname, operator, value, fieldtype}.
    make_filter_tuple(doctype, key, value) [doctype, key, "=", value], or [doctype, key, op, val] when value is [op, val].
    make_filter_dict(filters) Convert [[doctype, key, op, value], ...] to {key: (op, value)}.
    sql_like(value: str, pattern: str) -> bool Python version of SQL LIKE with % at the start, the end or both. No % matches a substring.
    filter_operator_is(value: str \| None, pattern: str) -> bool pattern is "set" or "not set". Another value raises frappe.ValidationError.
    filter_operator_timespan(value: str, pattern: str) -> bool True if the date is in get_timespan_date_range(pattern).
    filter_operator_between(value: Any, pattern: list \| tuple) -> bool True if pattern[0] <= value <= pattern[1]. None gives False.
    convert_type_for_between_filters(value: DateTimeLikeObject, set_time: datetime.time) -> datetime.datetime Make a datetime from a date with set_time. A datetime comes back unchanged.
    get_safe_filters(filters) Parse a JSON filter string. Keeps the string if it does not parse or parses to a number.
    operator_map Dict of operator to function, used by compare: ^, in, not in, =, !=, >, <, >=, <=, not None, None, like, not like, is, Timespan, between, Between. 
    from frappe.utils import compare, evaluate_filters

    Pitfalls¶

    • add_to_date with a date string and only minutes or seconds drops the time. add_to_date("2026-01-31", minutes=30) gives "2026-01-31". Pass a datetime string, or use hours.
    • add_to_date with a date object and a time unit returns a datetime.
    • getdate("") and getdate(None) return today, not None. Check for empty values before you call it.
    • cint("1,234") gives 0. Use cint(flt("1,234")).
    • flt(1.005, 2) gives 1.0 with the default rounding method. Pass rounding_method="Commercial Rounding" to round half away from zero.
    • compare needs the exact operator name. "Timespan" works, "timespan" returns False.
    • evaluate_filters needs a doctype key in doc.
    • orjson_dumps raises TypeError for date values. Pass default=json_handler or use frappe.as_json.
    • split_emails does not split on new lines. It changes them to spaces first. validate_email_address handles new lines.
    • frappe.utils.markdown sanitizes. frappe.utils.data.markdown does not.
    • get_ancestors_of ignores permissions. get_descendants_of and NestedSet.get_children apply them.
    • NestedSet.get_parent, get_children and validate_one_root read self.nsm_parent_field. That attribute is set only when the DocType sets nsm_parent_field.
